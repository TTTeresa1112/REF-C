# REF-C 参考文献核验工具

一个开源的参考文献核验工具：粘贴参考文献列表，自动通过 DOI 与公开学术数据库匹配核验，并生成可下载的 HTML 核查报告。

## 功能特性

- 按行自动识别参考文献（支持带或不带数字编号）
- 优先通过 DOI 调取数据库信息，与作者提供的题目、年份等交叉核验真实性
- 无 DOI 的文献直接进行数据库匹配核验
- AI 辅助识别文献类型与结构（书籍、会议论文、预印本、专利、网页等）
- 自动检测 DOI 不符、DOI 重复、可能重复、撤稿/更正等风险项
- 生成 HTML 核查报告，处理结果 24 小时缓存
- 支持最多 3 个并发核验任务，避免数据库接口被挤爆

## 环境要求

- Python 3.x（版本见 `.python-version`）
- Streamlit >= 1.35

## 快速开始

1. 安装依赖：

   ```bash
   pip install -r requirements.txt
   ```

2. 配置环境变量：复制 `.env.example` 为 `.env` 并填写：

   | 变量 | 必填 | 说明 |
   | --- | --- | --- |
   | `DEEPSEEK_API_KEY` | 是 | DeepSeek API 密钥，用于 AI 文献结构识别 |
   | `DEEPSEEK_BASE_URL` | 否 | DeepSeek API 地址，默认 `https://api.deepseek.com` |
   | `DEEPSEEK_MODEL` | 否 | 使用的模型，默认 `deepseek-v4-flash` |
   | `NCBI_API_KEY` | 否 | NCBI E-utilities API 密钥（推荐配置，可提高 Pubmed 查询限额） |
   | `MY_EMAIL` | 否 | 请求 NCBI 时使用的邮箱 |

3. 启动应用：

   ```bash
   streamlit run streamlit_app.py
   ```

4. 在浏览器中打开页面，粘贴参考文献列表，点击「开始核验」即可。

## 使用说明

页面顶部提供「开始核验 / 使用说明 / 关于」三个标签页：

- **开始核验**：输入参考文献并启动核验
- **使用说明**：核查原理与输出结果解读
- **关于**：项目介绍、开源许可与免责声明

每条文献的处理结果会缓存 24 小时；因网络问题失败的条目不会被缓存，可再次点击「开始核验」重试，成功条目将直接使用缓存。

## 免责声明

核查结果仅供参考。数据库信息可能不全或更新不及时，结果难免有不精准的地方，最终请以人工复核为准。
