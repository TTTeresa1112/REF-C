# REF-C 参考文献核验工具

一个开源的参考文献核验工具：粘贴参考文献列表，自动通过 DOI 与公开学术数据库匹配核验，并生成可下载的 HTML 核查报告。

## 功能特性

- 按行自动识别参考文献（支持带或不带数字编号）
- 优先通过 DOI 调取数据库信息，与作者提供的题目、年份等交叉核验真实性
- 无 DOI 的文献直接进行数据库匹配核验
- AI 辅助识别文献类型与结构（书籍、会议论文、预印本、专利、网页等）
- 自动检测 DOI 不符、DOI 重复、可能重复、撤稿/更正等风险项
- 生成 HTML 核查报告，处理结果 24 小时缓存
- 支持最多 3 个并发核验任务，避免数据库接口被挤爆
- 支持上传 Word 或 NLM/JATS XML，按题名和摘要初筛正文引用是否适配
- 引用初筛将判断结果分为“匹配 / 存疑 / 领域不符”，未取得摘要的项目单列为“未获取数据”，作者、单位、邮箱、ORCID 等误识别编号单列为“引用无关内容”
- 可对“存疑”项继续查找合法开放全文（优先 PMC/Europe PMC XML，其次开放 PDF），逐段复核并在找到支持证据后停止
- 可将“存疑”和“领域不符”条目生成独立的英文 `Reference Check Report`，用于直接反馈作者

## 环境要求

- Python 3.x（版本见 `.python-version`）
- Streamlit >= 1.35

## 快速开始

1. 安装依赖：

   ```bash
   pip install -r requirements.txt
   ```

2. 配置环境变量：复制 `.env.example` 为 `.env` 并填写：

   | 变量 | 必填 | 说明 |
   | --- | --- | --- |
   | `DEEPSEEK_API_KEY` | 是 | DeepSeek API 密钥，用于 AI 文献结构识别 |
   | `DEEPSEEK_BASE_URL` | 否 | DeepSeek API 地址，默认 `https://api.deepseek.com` |
   | `DEEPSEEK_MODEL` | 否 | 使用的模型，默认 `deepseek-v4-flash` |
   | `NCBI_API_KEY` | 否 | NCBI E-utilities API 密钥（推荐配置，可提高 Pubmed 查询限额） |
   | `MY_EMAIL` | 否 | 请求 NCBI 时使用的邮箱 |
   | `SEMANTIC_SCHOLAR_API_KEY` | 否 | Semantic Scholar API 密钥（不填写也可使用公开接口） |

3. 启动应用：

   ```bash
   streamlit run streamlit_app.py
   ```

4. 在浏览器中打开页面，粘贴参考文献列表，点击「开始核验」即可。

公开的普通核验默认限制为：单次最多 150 条、总计最多 60,000 字符、单条最多 1,500 字符。前端和服务端都会校验，DeepSeek 调用前还会再次截断。可通过 `PUBLIC_MAX_REFERENCES`、`PUBLIC_MAX_TOTAL_CHARS` 和 `PUBLIC_MAX_REFERENCE_CHARS` 调整。

普通核验在调用 DeepSeek 前还会检查文本是否具有年份、DOI、URL、期刊/出版信息或常见参考文献结构。明显的提问、提示词注入和其他无关内容会标记为“无效输入（未调用AI）”。需要 AI 分析的文本会作为不可信数据传入，并使用独立系统指令、固定输出格式和输出长度上限。

## 使用说明

页面顶部提供「开始核验 / 引用内容初筛 / 使用说明 / 关于」四个标签页：

- **开始核验**：输入参考文献并启动核验
- **引用内容初筛**：上传 Word 或 NLM/JATS XML；Word 需粘贴参考文献列表，XML 默认读取内嵌 `<ref-list>`
- **使用说明**：核查原理与输出结果解读
- **关于**：项目介绍、开源许可与免责声明

每条文献的处理结果会缓存 24 小时；因网络问题失败的条目不会被缓存，可再次点击「开始核验」重试，成功条目将直接使用缓存。

引用内容初筛首先根据公开数据库中的题名和摘要辅助判断，结果为“匹配 / 存疑 / 领域不符 / 引用无关内容”，未取得摘要的项目单列为“未获取数据”。参考文献输入框下方提供「点击统计条数」按钮，可随时确认识别到的文献条数。用户可对“存疑”项另行启动开放全文复核：系统在本地解析 XML/PDF、筛选最多 8 个高相关段落，再逐段调用 DeepSeek；找到明确支持证据后立即停止。未找到合法开放全文的项目保持“存疑”。还可将“存疑”和“领域不符”条目生成英文 `Reference Check Report` 直接反馈作者。

引用内容初筛使用独立访问码和每日额度。系统会先完成稿件解析、文献匹配和摘要获取，显示预计 DeepSeek 调用次数；只有用户二次确认后才预扣额度并调用 AI。默认每日额度为 200 次，完整配置见 [`citation_screening/README.md`](citation_screening/README.md)。引用内容初筛需要访问码才能使用，想要试用请联系 teresaleeovo@gmail.com。
